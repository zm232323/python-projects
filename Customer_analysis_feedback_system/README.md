### 🧠 Analyze Customer Feedback Using Python

A beginner-friendly Python project that analyzes customer feedback and categorizes it into **Positive**, **Negative**, and **Neutral** feedback.

</div>

---

# 🚀 Features

✅ Takes multiple customer feedbacks as input
✅ Detects Positive feedback
✅ Detects Negative feedback
✅ Detects Neutral feedback
✅ Displays feedback statistics
✅ Keyword search functionality

---

# 💡 How It Works

* User enters customer feedback
* Program checks keywords inside feedback
* Feedback is categorized automatically
* Results and insights are displayed
* User can search feedbacks using keywords

---
