### 🍿 Personalized Movie Recommendations Using Python

A beginner-friendly Python project that recommends movies based on the user's preferred genre, age, and movie ratings.

</div>

---

# 🚀 Features

✅ Genre-based movie recommendation
✅ Age restriction filtering
✅ Movie rating filtering
✅ Personalized recommendations
✅ Displays total recommended movies

---

# 💡 How It Works

* User enters:

  * Name
  * Age
  * Preferred Genre
* Program checks:

  * Movie genre
  * Age suitability
  * Movie rating
* Suitable movies are recommended to the user
