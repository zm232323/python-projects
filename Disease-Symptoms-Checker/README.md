### 🧠 Simple Disease Prediction Using Python

A beginner-friendly Python project that predicts possible diseases based on user-entered symptoms.

</div>

---

# 🚀 Features

✅ Symptom-based disease prediction
✅ High / Medium / Low match detection
✅ Multiple disease comparison
✅ Most likely disease prediction
✅ User-friendly loop system

---

# 💡 How It Works

* User enters 3 symptoms
* Program compares symptoms with stored disease data
* Match count is calculated
* Disease match level is displayed
* Most likely disease is predicted

---

# 🦠 Diseases Included

| Disease     | Symptoms                  |
| ----------- | ------------------------- |
| Flu         | fever, cough, fatigue     |
| Common Cold | cough, sneezing, headache |
| Malaria     | fever, chills, vomiting   |
